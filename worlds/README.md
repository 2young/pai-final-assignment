`maze.sdf` は `scripts/run_maze.sh` 起動時に、インストール済みの公式 `diff_drive.sdf` と `config/maze.json` から生成します。生成物を手で編集せず、配置はJSONで変更してください。

赤い箱はGazebo起動後に移動できます。自律走行では設定上の初期座標ではなく、PosePublisherで取得した現在位置を使います。壁配置は固定です。

固定障害物は合計9個です。従来の中央の3枚の壁に、以下の6個を追加しています。座標・寸法の単位はmです。

| モデル名 | 中心(X,Y) | 寸法(X,Y,Z) |
|---|---|---|
| `west_wall` | `(-8,0)` | `(0.6,3,1)` |
| `north_barrier` | `(0,9.5)` | `(3,0.4,1)` |
| `northwest_block` | `(-8,8)` | `(1.2,1.2,1)` |
| `northeast_block` | `(8,8)` | `(1.2,1.2,1)` |
| `southwest_block` | `(-8,-8)` | `(1.2,1.2,1)` |
| `southeast_block` | `(8,-8)` | `(1.2,1.2,1)` |

車両の寸法と安全余裕を考慮して通路を残しています。障害物に近すぎる位置へ箱を置くと到達できない場合があります。
配置変更後は、起動中の`run_maze.sh`をCtrl+Cで終了し、同じコマンドで再起動してください。Dockerの再ビルドは不要です。

登録オブジェクトには接触センサーも生成します。既定の接触モードでは低速で触れて停止し、`CONTACT_REACHED`を表示します。
